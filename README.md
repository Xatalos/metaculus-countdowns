A small-scale hobby project created with **Vite** + **React** + **TypeScript** - displaying countdown timers to some major future events (as predicted by Metaculus forecasters).

See the live result here: https://metaculus-countdowns.surge.sh/ (if it fails to load immediately, simply try reloading, as it sometimes goes down temporarily after a longer period of inactivity) (to update Surge properly: "npm install" -> "npm run deploy")
